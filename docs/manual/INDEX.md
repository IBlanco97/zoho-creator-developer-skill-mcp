## ¿Cómo usar este manual?

Este manual está organizado en **cuatro módulos** según las secciones de la aplicación. Cada perfil de usuario tiene acceso a secciones distintas. Consulta primero la sección **"Por perfil de usuario"** para saber exactamente qué módulos te corresponden.

## Flujos de trabajo transversales

Algunos procesos implican colaboración entre diferentes perfiles:

### Solicitud de permiso

```
Empleado (Portal A)          RRHH / PRL
────────────────────         ──────────
1. Nueva Solicitud Permiso → 2. Ver Solicitudes de Permisos (B §9)
                              3. Aprobar / Rechazar
4. Estado actualizado en
   Mis Permisos (A §3.1) ←
```

### Solicitud de EPI / Herramienta

```
Empleado (Portal A)          RRHH
────────────────────         ──────────
1. Nueva Solicitud EPI    → 2. Ver Solicitud EPI - Herramienta (B §8)
                              3. Aprobar y Gestionar
                              4. Registrar entrega
5. Confirmar recepción    ←   (botón "Confirmar" en A §4.2)
```

### Documentación CAE

```
RRHH / Gestor PRL
──────────────────────────────────────────────────────────────
1. Asignar técnico a cliente          → D §10 o B §7
2. Sistema genera lista de requisitos → automático (workflows)
3. Subir documento                    → C §7
4. Revisar semáforo por cliente       → C §3 / C §4
5. Enviar documentación al cliente    → C §8
6. Marcar como validado por cliente   → C §4
```

### Comunicado WhatsApp masivo

```
Gestor RRHH / Administrador
────────────────────────────────────────
1. Seleccionar plantilla   → D §9.1 (Enviar WhatsApp)
2. Elegir destinatarios    → Todos / Seleccionados
3. Redactar mensaje
4. Enviar (inmediato o programado)
5. Verificar envío         → D §9.2 (Historial WhatsApp)
```
